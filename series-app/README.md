# 🎬 SeriesHub - แพลตฟอร์มซีรี่ย์ออนไลน์ (Full Stack)

## ✨ ฟีเจอร์ที่เพิ่มครบแล้ว!

### 🎯 ฟีเจอร์หลัก
✅ **Authentication System** - NextAuth.js v5 (Login/Register)
✅ **Database** - SQLite + Prisma ORM
✅ **Reviews & Ratings** - รีวิวและให้คะแนนซีรี่ย์
✅ **Comments** - แสดงความคิดเห็น
✅ **Watchlist** - บันทึกซีรี่ย์ที่ชอบ
✅ **Watch History** - ติดตามความคืบหน้าการดู
✅ **Notifications** - แจ้งเตือนตอนใหม่
✅ **Recommendations** - แนะนำตามประวัติการดู
✅ **Admin Dashboard** - จัดการระบบแบบครบวงจร
✅ **Video Player** - เครื่องเล่นวิดีโอแบบกำหนดเอง

## 🚀 Quick Start

```bash
npm install          # ติดตั้ง dependencies
npm run db:push      # Setup database
npm run db:seed      # เพิ่มข้อมูลตัวอย่าง
npm run dev          # เริ่มต้นใช้งาน
```
